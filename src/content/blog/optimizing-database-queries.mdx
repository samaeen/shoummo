# Optimizing Database Queries

Database performance can make or break your application. Here are proven strategies for optimization.

## Indexing Best Practices

- **Composite Indexes**: Create indexes on frequently queried column combinations.
- **Covering Indexes**: Include all columns needed in the SELECT clause.
- **Avoid Over-Indexing**: Each index adds overhead to write operations.

## Query Patterns

```sql
-- Bad: Full table scan
SELECT * FROM users WHERE email LIKE '%@example.com';

-- Good: Index-friendly query
SELECT * FROM users WHERE domain = 'example.com';
```

## Monitoring & Profiling

Use tools like `EXPLAIN ANALYZE` to understand query execution plans and identify bottlenecks.

### Key Metrics
- Query execution time
- Index usage statistics
- Cache hit ratios

Remember: **Measure before optimizing**. Premature optimization is the root of all evil.
